# 漫剧平台内容安全审核系统

基于 Seedance 2.0 公开合规指南设计的三层内容审核架构。

## 三层架构

| 层 | 职责 | 第一期 |
|---|---|---|
| L1 敏感词库 | 关键词精确/变体命中 | ✅ |
| L2 规则引擎 | 组合规则、上下文判定、风险评分 | ✅ |
| L3 AI 模型 | 语义/多模态/生成后回检 | Phase 2 |

## 分类依据

Seedance 2.0 第八节：
- **100% 触发（高危）**：政治敏感 / 违法违规 / 名人肖像 / 版权侵权
- **谨慎使用（中危）**：宗教相关 / 暴力元素 / 性感类
- **平台补充（低危）**：广告导流
