系统总览：三层协同审核架构
基于 Seedance 2.0「综合判定」逻辑工程化：审核不是"出现某个词就拒绝"，而是 关键词风险 + 整句语义 + 人物/版权识别 + 输入素材 + 生成结果 的组合判定。系统将这一逻辑拆为三层——词库层负责关键词命中，规则引擎层负责组合规则与风险评分，AI 模型层负责语义/多模态/生成后回检，三层产出风险分逐层累加得出最终处置。

审核链路 输入 → L1 → L2 → L3 → 处置

📥 输入

提示词 / 素材
  • 角色·场景·道具文本
  • 分镜提示词脚本
  • 参考图/视频/音频
→

L1 敏感词库

关键词风险层 · 必经
  • 8 类分类 × 3 级
  • 预置只读 + 自定义增删改
  • 精确 + 变体识别
  • 产出：命中词 + 关键词分
→

L2 规则引擎

组合规则层 · 必经
  • 条件组合规则
  • 上下文判定（刀剑×博物馆）
  • 人物/版权标识叠加
  • 风险评分 + 阈值
→

L3 AI 模型

智能层 · 按需/回检
  • 整句语义检测
  • 图/视频/音频多模态
  • 生成中间 + 最终回检
  • 未成年人/真人/版权识别
→

📤 处置

放行 / 拦截 / 复核
  • ✅ 放行生成
  • 🟡 二次确认
  • 🔴 硬拦截
  • 🔁 送人工复核
三层逐层累加风险分：L1 关键词命中 → L2 叠加组合规则与上下文评分 → L3 叠加语义/多模态判定。任意一层命中"高危"可直接触发硬拦截；"中危"组合触发二次确认；低危仅标注。L1 通过不代表放行——L2/L3 仍可拦截，提示词通过也不代表最终生成成功。

综合风险评分模型（文档第四节的工程化）

文档原话："风险分数 = 关键词风险 + 整句语义风险 + 人物身份风险 + 版权相似性风险 + 参考素材风险 + 预期画面风险 + 最终生成结果风险"。本系统将其映射为可配置权重：
L1 · 敏感词库管理
关键词风险层。系统预置词库由平台合规团队维护（只读），对应 Seedance 第八节"必须规避/谨慎使用"分类；创作者/企业可自建自定义词，增删改后实时生效于 L1 检测与第⑤页演示。

L2 · 规则引擎配置
组合规则层。把"同一个词在不同上下文风险不同"工程化为可配置规则：条件组合（分类×等级×命中数×上下文标记×素材类型×人物/版权标识）→ 动作（硬拦截/二次确认/标注/送 AI 复核），并叠加风险评分。
